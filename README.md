# Loan Approval Prediction using Random Forest & SHAP

A beginner-level machine learning project that predicts loan approval using a Random Forest Classifier and explains predictions using SHAP (Explainable AI).

### 🎯 Objective
The goal was to learn how an ensemble machine learning algorithm works and how SHAP helps interpret model predictions.

### 🛠️ Technologies
- Python
- Pandas
- Scikit-learn
- SHAP
- Matplotlib

### ⚙️ Approach
- Created a small, sample dataset with 20 records.
- Trained a Random Forest Classifier to predict loan approval.
- Used SHAP to understand how income, credit score, and loan amount influenced individual predictions.
- Visualized feature contributions using SHAP plots.

### 📌 Key Learning
Gained practical experience with Random Forest classification and explainable AI using SHAP.

**Note:** This is a learning project using a small sample dataset, not a production-ready loan approval system. The results are illustrative and should not be generalized to real-world lending decisions.
